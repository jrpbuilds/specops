# Architecture

OpenSpec owns readiness, artifact instructions, validation, and archival. SpecOps has a thin shell-free OpenSpec adapter, seven least-privilege agents, atomic coarse run state, repository identity, validation evidence, one independent reviewer, and bounded repair.

The active plugin exposes five commands and six workflow tools. Native OpenCode tasks and questions perform delegation and interaction; tools reconcile boundaries and persist safety gates. There is no scheduler, capability graph, dispatch protocol, custom schema, workflow tier, tribunal, or automatic mode.
